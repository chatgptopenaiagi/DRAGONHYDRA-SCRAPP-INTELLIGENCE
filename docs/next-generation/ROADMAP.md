# Research and engineering roadmap

1. Collect timestamped, permissioned odds snapshots with complete period, line, settlement and suspension semantics. Test against replay fixtures and verify source times independently before presenting current market coverage.
2. Extend football research beyond its 10,000-observation scope with source-specific event indexing and paginated joins on both backends. Check migration rollback and provenance on representative archives.
3. Evaluate team-strength models against the frozen league priors on independent seasons, with point-in-time rosters and timestamps for corrections. Report uncertainty and retain experiments that score worse.
4. Add sports only when a provider event identity, raw evidence and a new sport-specific acceptance capture are available. Tennis, volleyball, handball and table tennis have no verified scoreboard adapter in this release.
5. Requalify live PostgreSQL, Joomla, optional model inference and any new installer architecture separately. The current distribution targets Windows x64. Android clients in the GENESIS repository use a different service contract.
