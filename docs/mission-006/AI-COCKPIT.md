# AI conversation cockpit

The cockpit shares existing protected provider configuration with Cloud AI Control Center. Five company cards represent OpenAI, Anthropic, xAI, Microsoft developer services and Manus. Microsoft offers Azure OpenAI, Foundry model inference or Copilot Studio Direct Line. Consumer Copilot is not an inference API. Local OpenAI-compatible inference remains available separately.

Enable a connection, save its key through the masked input and test it. Choose a real model returned by the provider or your actual Microsoft deployment. Authentication success does not prove inference balance. Open Chat sends messages only when you press Send. Each conversation is bound to its original provider, endpoint and model. Changed configuration requires a new conversation or restoring the previous configuration.

Use Conversations and tool permissions to start a conversation with explicitly selected tools. This authorizes bounded results from those tools to be shared with that provider during that conversation. No entire database is sent. The last 20 text messages, up to 32 KB, provide conversational context; full history remains stored locally. A single turn allows at most three model requests and four tools per response. Daily application request limits cover only this workspace, not other account usage. A provider may charge for each model request. Cost estimates are unavailable when pricing cannot be verified.

Tool receipts retain actual results, timestamps and fingerprints. Records are evidence; AI messages are interpretations. A model can propose an import, synchronization or engineering diagnostic. Execute or decline that proposal in Tool registry. A cloud model cannot execute shell commands or release the SQL guard.

Move chat by its title bar, resize from the corner, dock right, expand, or minimize to the AI chat button. It stays available across tables and charts. Search and resume conversations, copy messages or export JSON. Browser localStorage holds only presentation settings and the last conversation ID, never API keys or message contents. Chat content is retained in the workspace SQLite database and included in local database backups; these backups may contain private conversations and should not be published.

Stop response stops waiting and prevents further local tool/model calls after the bounded active request. It cannot guarantee that a remote provider stops computation already submitted. Manus supports a remote stop request. Interrupted turns are marked INTERRUPTED on restart and are never automatically replayed. Retry is a deliberate new potentially billable request.

Manus preserves a task across follow-up messages; Copilot Studio preserves a Direct Line conversation. Inspect remote response retrieves genuine messages. No external action approval is automated. These protocols do not have a verified client function-call interface in this beta; explicitly attached inspected tool receipts provide bounded context instead. Manus task cost is not controlled by a chat token cap.

Roundtable sends the question separately to two through five selected companies only after its explicit checkbox. Replies remain independently labeled. It does not silently create a sixth synthesis call. Unconfigured companies show NOT CONFIGURED.

Hardware monitor uses psutil Windows counters and NVIDIA-SMI when available. CPU temperature and network attribution to individual processes are UNAVAILABLE unless measured by a supported interface. Network rates are system-wide. No kernel sensor driver is installed.

Codex engineering attaches an existing current-user Codex App Server WebSocket Unix socket and existing thread. Configure the authorized workspace and thread ID; the bridge checks the thread's workspace before steering its active turn or resuming the same idle thread. It never creates/forks a thread, starts another worker, restarts the daemon or reads conversation text. Diagnostic jobs retain receipts. Disconnect by disabling the attachment. If the App Server is unavailable, recover it through the normal Codex application.

Tool registry can enable or disable individual tools and exposes a separate optional local MCP endpoint on the existing server. MCP uses a separate user-ACL-protected credential in private/mcp-client.json, permits enabled bounded read tools only, and never permits import, SQL-write or Codex actions. Compatible local clients must support stateless Streamable HTTP JSON responses (protocol 2025-06-18); SSE is unavailable. Keep the private client configuration out of shared backups and repositories. Remote MCP execution is not implemented in this beta. ChatGPT-specific account plugins cannot be imported as standalone runtime integrations.

Live limitations at this engineering checkpoint: API-Football authentication and historical collection were verified. OpenAI key authentication passed but inference is blocked by exhausted API credits. Claude, xAI, Microsoft and Manus have adapter/mock acceptance only until valid owner account access is supplied. SQL queries and writes remain blocked by the existing maintenance guard. No live SQL result or cloud conversation is claimed from mock acceptance.

A launcher refuses to reuse a different DRAGONHYDRA version already serving the selected dataset. It leaves that service and mode unchanged. Select a separate candidate data directory and free port for side-by-side review, or deliberately stop the original service only after a verified upgrade and rollback plan. Original beta.1/beta.2 remain recoverable. Codex recent operations are limited to diagnostics submitted through this bridge; the tab does not expose the full CLI transcript, arbitrary shell controls or all activity from unrelated engineering sessions.
